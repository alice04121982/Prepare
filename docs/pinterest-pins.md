# Pinterest pins: titles, descriptions and links

Copy for the 11 pins in `public/pins/`, drawn by `scripts/pins.mjs`.
Profile: pinterest.co.uk/staypreparedsite. Written 23 October 2026.

Rules, from `docs/tone-of-voice.md` and `docs/monetisation-plan.md`:

- Pins link to the site, never straight to Amazon. The site carries the
  disclosure, and Pinterest trusts pins that lead to a real page more.
- Keywords go in plain sentences. Pinterest now gives hashtags little
  weight, so there are none.
- The first 50 characters of a description show before "more", so the
  answer comes first.
- Facts match the pin and the page it links to. No urgency, no fear.
- Titles stay under 100 characters and descriptions under 500.

### 8. Free help in a power cut

- **Description:** The Priority Services Register is free, run by your
