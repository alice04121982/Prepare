# Prepare

A practical, non-alarmist website that helps people understand what to keep
on hand for social disruption (power/water/supply disruptions, extreme
weather, and similar) and realistically how long different levels of
preparation last. Built on the premise that community and mutual aid, not
"save yourself" thinking, is what actually gets people through disruption.

See [PLAN.md](./PLAN.md) for the full project plan: site map, tone
guidelines, tech approach, and build phases.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Stack

Next.js (App Router) + TypeScript + Tailwind CSS.
